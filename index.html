Flagship research ICME 2026 submission

DPADD-ES — Audio Deepfake Detection

A detector that tells real speech from AI-generated speech — even when the fake comes from a voice generator it has never encountered before.

The problem
Detectors learn the background noise instead of the voice, so they collapse on new generators. The challenge baseline drops from 0.95 F1 in validation to 0.63 in test.
What I built
A mask module that splits each recording into two orthogonal latent streams — speech and environment — using a Frobenius orthogonality loss, so the model can only learn artefacts in the voice itself. Wav2Vec2 → BiLSTM → multi-head attention → 5-class head.
Result
0.8923 macro-F1 on CompSpoofV2 (250,000 clips, 5 classes). Submitted to the ICME 2026 Grand Challenge, ESDD2 track.
  • PyTorch
  • Wav2Vec2
  • BiLSTM
  • Multi-head attention
  • CompSpoofV2

AuraCommerce — Agentic BI Dashboard

Three AI agents that watch an e-commerce database around the clock and explain, in plain language, what just changed.

The problem
Operations teams need live KPIs and anomaly alerts — but a dashboard that goes dark whenever the LLM API does is worse than no dashboard at all.
What I built
An Analyst → Sentinel → Reporter pipeline on FastAPI. The Sentinel reasons with GPT-4o-mini when an API key is present and falls back to deterministic rule logic when it isn't, so the system never has a hard dependency on the model.
Result
Zero-downtime anomaly detection, six live Plotly.js charts, on-demand PDF reports, and Prometheus metrics for scraping.

Gmail AI Semantic Autopilot

An always-on daemon that reads your inbox with Claude and files it for you — by meaning, not by keyword.

The problem
Gmail's filters match words, not intent. "I'd love to reconnect" from a cold sales rep and from a client chasing a contract deadline look identical to a rule engine.
What I built
An OAuth2 polling daemon that passes every unread message to Claude Haiku, which classifies it into one of seven intent categories and applies a label. Cold outreach and newsletters are archived before they reach the inbox — nothing is ever deleted.
Result
98%+ accuracy over 1,400+ emails, roughly 10 hours a week saved, at under $0.01 a day in API cost.
  • Python
  • Claude Haiku

Real-Time Ops Dashboard

A shared task board where a database write appears on every open screen faster than you can notice it.

The problem
Multi-agent systems need live visibility. Polling loops add lag, waste requests, and regularly show people state that is already out of date.
What I built
A Next.js client subscribed to Supabase postgres_changes over WebSockets, applying INSERT, UPDATE and DELETE events straight to React state. Writes render optimistically and roll back automatically if the server rejects them.
Result
Under 50 ms from database write to rendered change. No polling, no refresh button.
  • Next.js 16
  • React 19
  • TypeScript 5
  • Supabase Realtime
  • Tailwind CSS 4

NotebookLM MCP Server

A bridge that lets Claude Desktop read, cite and reason over your NotebookLM research without leaving your editor.

The problem
Carefully curated NotebookLM knowledge bases are locked away from the tools where the work actually happens, so people copy and paste — and lose the citations.
What I built
A TypeScript Model Context Protocol server that maps exported notebooks into Claude Desktop as retrievable context, with hard boundaries on what the model is allowed to draw from.
Result
Hybrid-RAG answers bounded strictly to notebook context, which sharply reduces hallucination on research questions. Ships with Windows-first setup and troubleshooting docs.
  • TypeScript
  • Node.js 18+
  • MCP
  • Claude Desktop

Clinical Comorbidity Dashboard

Which diagnoses travel together? Association-rule mining across 2,440 clinical visits, made explorable.

The problem
Comorbidity patterns sit buried in visit records and are almost never surfaced in a form a clinician can actually poke at.
What I built
An FP-Growth mining pipeline (minimum support 0.01, minimum confidence 0.50) over one-hot encoded visit transactions, wrapped in a Streamlit dashboard with real-time filtering by primary and secondary diagnosis.
Result
Roughly 300+ association rules, filterable live across dashboard, appointments, labs, demographics and advisory panels. Deployed to Streamlit Cloud.

  • FP-Growth
